Build a full-stack healthcare platform called **CHIKIT** designed for hospitals across India. The system acts as a **national health record platform** where hospitals, clinics, labs, pharmacies, doctors, and patients interact through one unified system.

The platform must be **multi-tenant**. Every hospital operates in its own workspace accessed via subdomains.

Examples
aiimsdelhi.chikit.app
apollohospital.chikit.app
fortisgurgaon.chikit.app

Hospitals are loaded from a **national CSV database containing all hospitals in India**. This CSV contains:

Hospital Name
Hospital ID
City
State
District
Hospital Type (Government / Private / Clinic / Diagnostic)

During staff login the system must allow **searchable hospital selection from this CSV**.

Use modern stack:

Frontend: Next.js / React
Backend: Node.js API / Supabase / PostgreSQL
Authentication: OTP + secure tokens
Storage: S3 compatible bucket for reports
Cache: Redis

UI must prioritize **speed, clarity, and minimal clicks for hospital workflows**.

---

CHIKIT CORE CONCEPT

Every citizen has a **Chikit ID** which acts as a national digital health identity.

Format example:

CHIKIT-XXXXXXXX

Example:

CHIKIT-7F4A29D1

A Chikit account stores:

Patient demographics
Prescriptions
Diagnoses
Lab reports
Doctor notes
Medication history
Allergies
Vaccination history
Hospital visits

Records are **append-only** and cannot be deleted by hospitals.

SECURITY REQUIREMENTS

Role Based Access Control

Receptionist cannot see full medical history
Doctors can access patient records during visits
Labs can only access tests assigned
Pharmacy only sees prescriptions

All medical records must be **encrypted at rest and in transit**.

---

ADDITIONAL FEATURES

Patient QR Code

Each patient profile generates a QR code containing the Chikit ID.

Hospitals can scan the QR code to retrieve records instantly.
