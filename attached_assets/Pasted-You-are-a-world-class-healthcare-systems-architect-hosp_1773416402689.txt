You are a world-class healthcare systems architect, hospital workflow expert, and full-stack engineer.

Your task is to design a complete healthcare platform called **Chikit**.

Chikit is a universal healthcare operating system used by hospitals, doctors, laboratories, pharmacies, and patients. The system connects multiple hospitals into a single secure network while maintaining strict patient consent and privacy.

The platform must reflect **real hospital workflows** and include dashboards for all hospital roles.

Your output must be extremely detailed and explain exactly how the platform works.

--------------------------------------------------

CORE CONCEPT

Chikit works as a **multi-hospital network** where each hospital has its own dedicated environment accessed via subdomains.

Example hospital logins:

aiimsjodhpur.chikit.app  
apollo.chikit.app  
cityhospital.chikit.app  
govhospitaldelhi.chikit.app

Each hospital operates independently but can securely connect to the wider Chikit healthcare network when patient consent allows record sharing.

--------------------------------------------------

LOGIN SYSTEM

Design the login architecture.

Main entry:

chikit.app

Users can:

• login to their hospital workspace  
• select their hospital  
• or be redirected to their hospital subdomain

Hospital subdomain example:

aiimsjodhpur.chikit.app/login

Login methods:

• email + password
• hospital ID
• OTP login
• biometric login for hospital devices
• SSO for hospital staff

User roles determine dashboard access.
